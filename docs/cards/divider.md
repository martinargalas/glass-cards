# Divider

`custom:glass-divider`

A soft rounded line between cards – or a small heading with an icon.

**Good for:** separating parts of a panel.

## Quick start

```yaml
type: custom:glass-divider
name: Energy          # optional heading
icon: mdi:flash
line: false           # just the heading
```


## Options

<!-- options -->
| Option | Type | What it does |
| --- | --- | --- |
| `name` | string | Name |
| `icon` | string | Icon |
| `line` | boolean | Line |
| `width` | string \| number | Length |
| `thickness` | number | Weight |
| `opacity` | number | Opacity |
| `margin` | number | Margin |
